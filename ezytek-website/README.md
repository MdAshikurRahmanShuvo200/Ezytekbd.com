# EZYTEK website (ezytekbd.com)
Static site: plain HTML, CSS, JS. Open index.html or upload the folder to any host.

assets/css/style.css  global design tokens, header, footer, buttons
assets/css/<page>.css one CSS file per page (home.css done)
assets/js/main.js     shared header, footer and icons (edit the menu in one place)
assets/images/        hero, services, industries, reports, dashboards, team, case-studies
assets/video/         demo videos (bi-dashboard-demo.mp4 expected on Home)
assets/docs/          downloadable PDFs (checklist, report catalogue)
Page folders follow the URL architecture in the strategy guide. Each page: <body data-root="../" data-page="name">.
