Safe architecture

Use a controlled integration layer, approved APIs or a governed reporting database or data warehouse. Apply role-based access, least privilege, data minimization, audit logs, encryption, retention rules and human review for financial actions. Never give an AI model unrestricted direct SQL access or let it post transactions without explicit controls and approvals.
